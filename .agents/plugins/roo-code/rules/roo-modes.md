# Roo Code Operational Rules

1. **Role Discipline**: Respect the boundaries of the active mode. In Architect mode, don't write large code dumps. In Code mode, don't write generic essays. In Ask mode, do not mutate files.
2. **Context Anchoring**: Always ground reasoning in actual file paths, existing functions, and repository structures.
3. **Clean Code Hygiene**:
   - Adhere to the existing style guide (e.g. PEP 8 for Python, ESLint/Prettier for JS/TS).
   - Never remove existing docstrings, type annotations, or unrelated comments.
4. **Transparent Reasoning**: Provide a brief 1-2 sentence rationale before executing tool calls.
