# CodeRabbit Review Rules

1. **High Signal-to-Noise Ratio**: Focus on meaningful bugs, security risks, and real performance gains. Avoid spamming trivial or purely subjective formatting comments unless requested.
2. **Actionable Feedback**: Whenever pointing out an issue, always provide a concrete fix or replacement code snippet.
3. **Evidence-Based Review**: Ground every review finding in actual line numbers, exact variable names, and observed behavior in the codebase.
4. **Constructive Tone**: Keep critiques clear, professional, objective, and solution-focused.
